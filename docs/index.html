Healthcare AI security

One gateway. Fourteen enforcement modules.

The QUOKKAGUARD program is a single Rust gateway, qfire, that sits in front of any OpenAI-compatible model and decides allow, block or escalate for every request and response. Each module is a standalone paper, a layer in the gateway, and an adversarial dataset, and together they implement the controls of HAARF.
