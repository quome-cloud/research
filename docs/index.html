Featured program · Healthcare AI security

One gateway. Fourteen enforcement modules.

QUOKKAGUARD is a single Rust gateway, qfire, that sits in front of any OpenAI-compatible model and decides allow, block or escalate for every request and response. Each module is a standalone paper, a layer in the gateway and an adversarial dataset. Together they implement the controls of HAARF, the regulatory framework written with the Task Force for AI Agents in Healthcare.
